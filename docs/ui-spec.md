# MaskCanvas UI 规范 v2

更新：2026-10-22。交付为直接生成的静态 PNG 效果图，不是可运行 UI。旧稿不再作为视觉依据。

## 方向

采用用户在本轮明确选择的浅色专业影像工作台方向：灰白底、克制工具栏、大画布、清晰中文。

强调照片与当前任务；连接和技术配置放设置页，不在编辑器顶栏堆端口、GPU、模型与 Agent 徽章。不以圆角卡片墙展示所有能力。

## 新视觉系统

| 项目 | 规范 |
|---|---|
| 背景 | 暖中性白 #F7F7F2，普通面板接近白，画布底 #DDDED8 |
| 主文字 | 近黑 #222321，次级中性灰；字体参考 PingFang SC / Noto Sans SC |
| 操作 | 主要按钮近黑白字；低饱和鼠尾草绿 #748568 用于选中/焦点 |
| 编辑 mask | 琥珀金 #DDB15C，细描边和适度透明，不全图罩色 |
| 保护 mask | 灰蓝 #718BAF，锁与斜纹辅助，不只靠颜色 |
| 上下文 | 灰虚线，标“参考范围”，不与允许修改范围混淆 |
| 形状 | 简洁 4–8px 圆角；少阴影，以留白/对齐/分隔线建立层级 |
| 字级 | 正文 14–16，区域标题 18–22，入口页标题 30–36；数字清晰 |
| 密度 | 顶栏约 64、工具栏约 56、检查器约 300；每屏一个主要动作 |

设计构图基准 1600×1000。生成图片按实际文件尺寸交付，不以概念基准冒充精确像素。尺寸有差异时保持比例，不拉伸。

## 编辑器布局

顶部：产品名、项目名、精修/标注/协作/任务、保存状态、导出。中央照片占主要面积；左侧窄工具栏；右侧当前任务与意图。底部轻量版本条；未选任务时不显示多余高级参数。

画布默认适应；支持 100%、局部放大、平移、导航缩略图。检查时优先隐藏 mask，避免遮住接缝。照片与任何人脸均为合成示例，不使用私人家庭照做图稿。

## 关键面板

- 标注：编辑/保护切换；画笔与橡皮；边缘过渡；意图；保存。mask 与上下文始终可分别显示。
- 协同：Agent 提议列表、区域来源与已修订标记；选中一条才显示详情；支持修改区域与人工接管。
- 自主：任务目标、不可改对象、本地/远端处理策略、重试预算；执行进度与等待原因可见。
- 验收：原图/候选分割、原尺寸局部、保护检查、视觉检查；选择接受或退回，不把生成成功当自动接受。
- 交接：编辑包与成品照片两类导出；包内容摘要、来源版本、导入结果入口；无密钥和绝对路径依赖。
- 设置：Agent 连接与模型可用分开检查；本地生成不等于允许远端视觉；敏感字段在设计中仅显示占位。

## 状态文案

| 状态 | 用户可见文案与下一步 |
|---|---|
| 未连接 | “尚未连接” + 检查连接；不能预先显示绿色成功 |
| GPU 忙 | “等待设备空闲” + 已知队列位置；未知耗时不编造 |
| 生成 | 显示实际可得进度；无百分比时显示阶段/已用时间 |
| 结果返回 | “候选待验收”；进入 S06，不直接覆盖 |
| 检查未通过 | 展示失败项，可看差异、改标注或重试 |
| 受理状态未知 | “正在核对任务状态”；不显示可反复点击的提交按钮 |
| 基准已变 | “基准版本已更新，结果已保留”；允许查看、重新执行或回到当前版本 |
| 自主需要人 | 原因与已完成内容可见；“接管任务” |

## 一致性与可访问性

不支持的参数不展示。保护区不提供“允许颜色微调”与硬锁混合语义；需要调色应新建允许编辑范围。

焦点可见；按钮有文本/工具提示；mask 颜色配锁、斜纹和名称；对比手柄可键盘操作。首版桌面优先，窄屏折叠检查器，不承诺移动端精细修图。

图中的连接状态、差分数字、版本、耗时均为演示，不能用于验收实现。文字与操作规则以本文和交互文档为准，图像生成可能存在细小文案偏差。

## JSON 交接修订

S07 当前实现为 JSON 交接页、查看/复制 JSON 弹层与 JSON 文件/粘贴导入，取代旧 ZIP 图稿。图片独立引用；导入只载入标注。下一阶段协作页需独立展示 Agent 建议列表、用户调整和确认状态，不能以现有直接保存标注替代完整确认流程。见 [agent-workflow.md](agent-workflow.md)。
