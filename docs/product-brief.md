# MaskCanvas 产品简报 v2

更新：2026-10-22。完整行为与验收以 [requirements.md](requirements.md) 为准。

## 一句话

让人和不同 AI Agent 共同完成可控、可检查、可移交的照片精修。

## 问题

现有流程把选区、保护对象、局部意图和合成规则藏在长提示词里。结果容易出现下颌裁断、重影、旧衣残留和接缝；人工与 Agent 之间缺少稳定的共享编辑数据。

## 定位

独立本地工作台 + 编辑核心 + 通用 MCP + 可移交编辑包。Qwen Image 与 GPT Image 2.5 提供候选内容；画布是人工入口，MCP 是 Agent 入口，二者不各建一套修图管线。

## 目标用户与任务

日常摄影者、人像创作者和已有 Agent 的用户。自然修饰为默认场景；换装、发型和轮廓重设计由用户明确指定。

| 使用方式 | 价值 |
|---|---|
| 人工标注后交给 Agent | 精确控制范围，执行者无需猜坐标 |
| 人与 Agent 协同 | Agent 提议，人修正，所有操作可见可回退 |
| Agent 自主执行 | 目标明确时无人值守处理，异常可接管 |

## 首版范围

JPEG/PNG 项目；精细选区与硬保护；Agent 建区；双后端与异步任务；版本/候选/对比；有限授权自主任务；编辑包跨客户端交接；精度与隐私验收。

不含 RAW 显影、完整 PS 替代、视频、多用户实时协作和云账号体系。采用普通浏览器画布；原生壳与专业软件桥接可后置。

## 成功标准

- 三模式共用同一项目、区域与版本，能相互接管。
- 保护区域与选区外在相同无损基准上零变化。
- 原尺寸检查身份、边缘、接缝和残留，不能仅看缩略图。
- 标注包可跨目录、跨 Agent 执行并回导结果。
- 远端分析与生成只在允许的目的地发生。
- 性能、成功率和耗时以实测记录，不沿用旧稿的固定承诺。

## 当前交付与决策

本轮重整需求和方案，并直接输出全套 PNG 效果图与交互图，不写 HTML。旧视觉稿已被用户否定，新版不继承旧稿的布局或配色。画布实现是否复用 InpaintCanvas，需在技术差距试验后决定。
