## 图稿说明

每个页面聚焦一个任务，不把所有参数、连接、队列和高级功能堆到主画布。编辑使用琥珀金，保护使用灰蓝与锁/斜纹，参考范围用虚线。验收时照片优先，隐藏蒙版遮挡。

本套为一套完整产品方向，不是三个互斥概念选项。S06 与 S08 已进行针对性修正：并排布局与选中对比方式一致，设置导航去除了范围外的团队协作入口。初稿 `s06-review.png` 和 `s08-settings.png` 留作迭代记录，不纳入最终 10 张交付图。

生成图中的个别小字、图标或细节仅作视觉表达；完整操作与范围约束以需求、交互规范为准。设计稿中的候选效果不是 Qwen/GPT 实际照片编辑效果测试。
