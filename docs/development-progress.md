## 迭代 05 · 图片授权、显式上下文、JSON 图片绑定与质量验证

已实现与复核：

- 项目授权独立写入 `permissions.json`，绑定当前图片基准、用途、后端、目的地、到期时间和可选计划额度。撤销即时生效；生成额度按原幂等键消费，重试不重复扣。作业文件落盘失败会清除未持久化的内存任务，同键可恢复额度预留。
- MCP 观察与 PNG 导出都检查本项目分析授权。客户端身份来自受信本机 `MASKCANVAS_AGENT_CLIENT`，工具参数不能冒用另一身份；旧整库图像开关不再授予权限。产品授权不是本机文件/Shell/原始 HTTP 的安全沙箱。
- GPT 节点适配按现场真实显示名和参数验证，只允许三个已列出的 GPT 模型，使用原像素补边上下文，严格拒绝尺寸不符。确认快照冻结 Comfy 中转 origin 和模型；远端生成默认关闭且须项目授权，不回退到别的后端。实际最终云路由仍取决于节点私有配置，未冒充已经验证该云路由。
- 每个 edit 可显式设置原图像素 `context`，画布有独立虚线轮廓。保存会验证包含有效编辑像素且不越图界，keep 不能携带上下文。上下文不扩大编辑支持。实际页面验证了有效范围保存和缩小后拒绝，失败时草稿仍保留。
- JSON 可显式绑定目标工作区已导入的照片，核对规范基准 PNG 的 SHA-256、尺寸、色彩与坐标后创建新草稿。普通导入仍保持原项目/版本检查，不静默重绑定。ID 碰撞重映射，目标人工标注不变，外来确认失效。来源说明随 JSON 返回，不另建持久审计日志。
- 新增候选拒绝操作，保留图像与历史，不移动基准或改变标注修订；重复拒绝幂等，原图/接受版不可拒绝。
