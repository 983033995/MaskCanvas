# MaskCanvas 交互流程 v2

更新：2026-10-22。状态：设计规范。对应静态图见 [design/v2](../design/v2/README.md)，非 HTML 原型。

## 三模式主流程

| 模式 | 进入 | 操作 | 汇合点 |
|---|---|---|---|
| 人工 | S01 导入，选择人工标注 | S03 画编辑/保护区域，写意图；S02 生成，或 S07 复制/导出 JSON | 候选回导/返回后到 S06 |
| 协同 | S01/S02 进入协作 | S04 Agent 提议 → 人修改区域/意图 → 执行冻结计划 | S06 验收 |
| 自主 | S05 写目标、对象、保护与预算 | Agent 观察 → 分割/建区 → 执行 → 检查；有限重试 | 满足策略则接受，否则 S06/人工接管 |

汇合流程：候选 → 硬约束检查 + 原尺寸视觉检查 → 接受为新版本 → 继续编辑或导出。拒绝候选不删除原图和历史。

## 页面之间

S01 导入/最近项目 → S02。S02 选标注 → S03；选协作 → S04；选任务 → S05；候选/对比 → S06；导出/交接 → S07；连接入口 → S08。返回项目保留当前版本、标注和视图位置。

## 标注

1. 画矩形、套索或笔画，创建原图坐标区域；橡皮仅改当前 mask。
2. 选择编辑或保护属性，填写局部意图。保护无需 prompt。
3. 画笔、向内过渡、反选等只改变当前标注；不修改原图像素。
4. 上下文框由编辑范围加参考边距产生，并清楚标为“参考范围”；不得当作扩大编辑授权。
5. 空 mask 禁止执行；小选区允许；越界裁剪或报错必须明确。
6. 多区域不同意图要有执行顺序；重叠时标出影响，不盲目取并集后混合提示词。

## 协同

Agent 的区域有来源标签“Agent 提议”；人修改后标“已修订”。同一条任务的目标、范围与保护对象可一起查看。点击“按此计划生成”冻结输入快照。Agent 不直接绕过编辑核心写入已接受版本。

用户可接管选区或任务；不再向原 Agent 发起新动作，已有后端任务按自身可取消能力处理；接管不是杀进程或打断其他项目。

## 自主

任务先明确目标、对象、允许操作、保护对象、分析与生成目的地及尝试上限。默认自然修饰，改变外观需明确指定。提交后只在已允许范围内继续，不反复确认常规步骤。

无视觉/分割能力、保护边界不清、预算耗尽、无法自然衔接或目的地未允许时，进入“需要人工”。保留问题定位、mask、候选与原因。人工从 S04/S03 接管后可恢复任务。

## 作业与取消

| 事件 | 系统行为 | 用户下一步 |
|---|---|---|
| 提交 | 校验能力/权限/输入，冻结计划，返回唯一 job ID | 可离开任务页 |
| 排队 | 等待执行设备，不占用假的生成进度 | 查位置或取消本任务 |
| 执行 | 展示已知阶段与已用时间 | 可继续其他标注 |
| 返回 | 对齐候选并本地合成，先验硬约束 | 进入 S06 |
| 明确失败 | 保留 mask/意图和错误 | 修改后新提交或明确重试 |
| 网络超时/未知 | 使用既有外部 ID 核对，不重新提交 | 等待核对/人工处理 |
| 排队取消 | 仅移除自己的 prompt/job，确认后显示已取消 | 可继续编辑 |
| 运行取消 | 显示请求状态与后端能力；若不能安全取消，说明等待结束并丢弃候选 | 不得全局 interrupt |
| 重启恢复 | 持久化 ID 查询已有任务 | 不重复生成 |

执行中可以修改标注；当前任务始终使用旧快照。标注 revision 或基准过期时，返回结果保存为候选分支，不能自动盖掉最新工作。

## 验收

S06 默认隐藏 mask，提供分割/并排/临时原图、100% 和差异图。可选择原图、上个接受版作为比较基准。

先显示真实检查的范围：保护 mask 与有效编辑范围外。展示“保护区变化 0 px”等数据必须来自实际检查；图稿数字只是示例。再由人工或具备视觉能力的 Agent 检查身份、发际、脸颈、衣领、遮挡、接缝和全图平衡。

硬约束失败不可自动接受；视觉不确定则输出待验收候选。接受产生新不可变版本；拒绝保留历史。版本基准发生冲突时只能查看/重新执行/显式回到对应分支，不自动合并。

## JSON 与照片导出

S07 区分成品照片与给 Agent 的标注 JSON：

- 成品 PNG 保留无损基准；JPG/改尺寸为单独派生操作。
- JSON 记录图片引用/哈希、基准与 revision、原图坐标区域、保护和意图；复制或下载即可，不要求 ZIP。
- 导入/粘贴 JSON 要匹配项目、图片与版本，完整校验几何，只载入标注，不自动生成。跨设备必须先取得并绑定对应照片，不能凭引用恢复图片。
- Agent 建议草稿与用户确认后的正式计划必须分离；下一阶段以服务端确认状态决定能否执行，不信任 JSON 自填的 confirmed 字段。

完整新流程与已实现边界见 [agent-workflow.md](agent-workflow.md)。旧图稿的打包概念已由本段取代。

## 连接设置

分别检查 Agent 协议连接、图像观察能力、设备可达、后端可编辑/mask 能力。一个检查成功不代表其他都成功。无模型连接时标注和 JSON 导出仍可用；本地服务不可用则说明无法保存并保持已载入内容，不冒充已同步。

## 快捷键

V 选择、B 画笔、E 橡皮、R 矩形、L 套索、H/空格平移；加减缩放、0 适应、1 原尺寸；Cmd/Ctrl+Z 撤销、Shift+Cmd/Ctrl+Z 重做。Cmd/Ctrl+Enter 仅在输入有效且非提交中触发生成；普通 Enter 在文字框换行。Cmd/Ctrl+S 保存项目，导出另用明确按钮。
