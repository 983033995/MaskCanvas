# 画布工具的回归约定

- 图像与 shape 坐标始终是原图像素；指针/布局是 CSS 像素，DPR 只作用于 backing store。
- 离屏 mask/tint 已是设备像素，彼此 `drawImage` 必须用 identity 或明确源/目标尺寸；禁止在合成时重复乘 DPR。
- 画笔预览与提交使用同一 shape/蒙版管线；橡皮在当前区域执行 subtract，不画一条颜色提示线冒充擦除。
- 笔尖圆环按实际直径 × 缩放绘制。不得为容纳圆环把落笔中心推离鼠标；超出照片的笔迹交给图像边界裁切。
- PointerCancel/Esc/工具切换应取消草稿，不能隐式提交。采集 coalesced points，拖动时不要逐点写 React 像素状态。
- 磁性套索是局部 RGB 边缘跟踪，不是完整主体分割。保留自由/多边形与手动修正，输出原图坐标 polygon。
- 改画布后必须测试 DPR 1/2、fit/100%/缩放+平移；分别检查按住、拖动、松手和保存坐标，不能以类型检查或截图代替。
- 检查工具坐标时根据当前 canvas rect 与照片变换计算位置，不硬编码旧窗口坐标。鼠标在照片外不应落笔。
