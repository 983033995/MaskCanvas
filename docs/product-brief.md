# MaskCanvas — Product Brief

## 一句话

让人用「画框/套索/涂抹」而不是「写长 prompt」来指挥 Qwen 精修照片，并且每一步都能对比、回退、验收。

## 背景

当前的本地 Qwen 精修流程是 prompt-first：

1. 人用文字描述要改什么、保留什么；
2. Agent 猜一个 crop；
3. Qwen 重绘整个 crop；
4. 人再手工做蒙版、羽化、拼回原图；
5. 出现鬼影/接缝/旧衣服残留，再改 prompt 或重做蒙版。

问题不在模型，而在**意图没有被几何化**：

- “只改下颌”没有变成 mask；
- “宝宝不要动”只是一句 prompt，不是硬约束；
- 每次修改都要重写整段描述；
- 生成结果和原图之间没有稳定的版本/对比。

## 用户

- 主要用户：需要精修家庭照、人像、服装/造型照片的创作者；本机有 Qwen/ComfyUI 或愿意用本地 GPU。
- 次要用户：让 Agent 自动跑批量修图的开发者；需要把人的选择转成结构化数据。
- 非目标用户：需要完整 Photoshop 图层/印刷/矢量能力的专业设计师；需要多人实时协作的团队。

## 核心 job-to-be-done

> 我看到照片里一个具体问题（下颌、发丝、领口、裙边、旧衣服），我想直接圈出来，告诉它“改成什么/不要动哪里”，然后马上看到可对比的结果，不满意就改选区再试。

## 价值

1. **更快**：框选 + 一句话，替代长 prompt + crop 计算。
2. **更准**：区域级 prompt/operation，keep 区域是硬约束。
3. **更可控**：版本、A/B、mask 可见，失败可定位。
4. **更隐私**：本地 Qwen/ComfyUI，图片不出机器。
5. **可自动化**：同一份 regions.json 可以被 Agent 读取，做批量或无人值守。

## 成功标准

| 指标 | 目标 |
|---|---|
| 首次编辑到第一次预览 | < 60 秒（GPU 空闲） |
| 单区域预览耗时 | 15–45 秒（1280px，3050 级别 GPU） |
| 需要手工算 crop/坐标 | 0 次 |
| 每次修改的可对比性 | 任意版本可 A/B，原图永远保留 |
| 隐私 | 0 次云上传（默认配置） |
| 一次验收通过率 | P0 阶段先记录基线，不设虚高目标 |

## 范围

### P0（MVP）

- 导入图片（拖拽/文件选择/剪贴板）。
- 矩形、套索、画笔、橡皮；蒙版叠加与羽化。
- 每个区域：operation、prompt、强度、keep 开关。
- Keep 区域（宝宝脸、背景、男士）优先于生成。
- 本地 Qwen/ComfyUI 生成；区域预览。
- 前后对比（分割/切换）、版本列表、接受版本。
- 导出 PNG/JPG + regions.json + masks。
- 本地 MCP server 暴露 annotations。

### P1

- SAM2 点选/框选自动出精细蒙版。
- 多区域队列、每区域独立 seed。
- 历史版本回滚、区域复制、快捷键完善。
- 项目自动保存/恢复。
- Photoshop UXP / Krita 适配器（导出选区为 mask）。

### P2

- 批量模板（人像/换装/商品）。
- Agent 自动创建区域、批量任务面板。
- 项目库、团队共享（本地/局域网）。
- 更多本地模型（FLUX Kontext、Qwen 2511 等）适配。

## 非目标

- 不做完整 Photoshop 替代（图层混合模式、印刷、矢量、3D）。
- 不做视频编辑/生成。
- 不做云端协作/账号体系。
- 不默认上传任何图片到第三方服务。

## 关键决策

1. **浏览器画布，而不是 Photoshop 插件**：跨平台、无需 PS 授权、易与 MCP 集成；PS/Krita 作为后续适配器。
2. **区域级意图，而不是整图 prompt**：每个 region 独立 operation/prompt；keep 区域是硬约束。
3. **先生成预览，再应用**：避免每次直接改原图；版本可回退。
4. **本地优先**：Qwen/ComfyUI 在本地 GPU；UI 只连 127.0.0.1。
