# MaskCanvas — UI Specification

设计基准分辨率：1440 × 900（桌面优先）。可交互稿：`design/ui-mockup.html`。

## 设计原则

1. **画布是主角**：工具栏和面板退到边缘，图片占据最大视觉面积。
2. **颜色即语义**：青色 = 要编辑；珊瑚红 = 保护；琥珀 = 队列/警告；绿色 = 成功。
3. **一次只处理一个区域**：右侧卡片是“当前意图”，不把十几个参数堆在画布上。
4. **结果可比较**：任何生成都能和原图/上一版并排或分割对比。
5. **Agent 可见但不打扰**：顶部只显示“已连接 / 已读取 N 个区域”，详细 JSON 在弹层里。

│ Top bar 56px: logo · project · undo/redo · zoom · compare · agent · export   │
├──────┬──────────────────────────────────────────────────┬────────────────────┤
│ Tool │ Stage                                             │ Inspector 380px    │
│ rail │  ┌────────────────────────────────────────────┐  │  编辑区域 / 保护   │
│ 64px │  │                                            │  │  ┌──────────────┐  │
│      │  │              Canvas / image                │  │  │ Job status   │  │
│      │  │       masks + region chips + compare       │  │  ├──────────────┤  │
│      │  │                                            │  │  │ R1 card      │  │
│      │  └────────────────────────────────────────────┘  │  ├──────────────┤  │
│      │  Canvas HUD: zoom · size · mask %                 │  │ R2 card      │  │
│      │  ┌────────────────────────────────────────────┐  │  ├──────────────┤  │
│      │  │ Filmstrip: V1 · V2 · V3 · V4               │  │  │ K1 keep card │  │
│      │  └────────────────────────────────────────────┘  │  └──────────────┘  │
│      │                                                  │  Generate / Apply  │
├──────┴──────────────────────────────────────────────────┴────────────────────┤

- Top bar: 56px.
- Tool rail: 64px.
- Inspector: 380px, 可折叠为 48px（<1280px 时变抽屉）。
- Status bar: 28px.
- Stage: 剩余空间；canvas 占 stage 的 1fr，filmstrip 固定 96px。

## Top bar

| 区域 | 内容 | 行为 |
|---|---|---|
| 左 | 产品标记 `MaskCanvas` + `Beta`；项目名下拉；图片尺寸 | 点项目名打开项目菜单（重命名/导出/关闭） |
| 中 | 撤销/重做；缩放 `- 62% +`；适应窗口；对比开关 | 撤销/重做禁用态；对比切换 split/off |
| 右 | Agent 状态胶囊；ComfyUI 队列；导出按钮；头像 | Agent 胶囊点开显示 MCP 地址/复制配置；导出打开导出弹层 |

Agent 胶囊两种状态：

- 绿色：`MCP 已连接 · 5 区域`
- 灰色：`Agent 未连接`；点开显示启动命令与端口。

## Tool rail

| 工具 | 快捷键 | 图标语义 | 说明 |
|---|---|---|---|
| 选择/移动 | V | 箭头 | 选中区域、拖动控制点 |
| 矩形 | M | 方框 | 拖出矩形蒙版 |
| 套索 | L | 套索 | 自由圈选；双击闭合 |
| 画笔 | B | 笔刷 | 涂抹蒙版；`[` `]` 调大小 |
| 橡皮 | E | 橡皮 | 擦除蒙版 |
| 智能选择 | S | 闪光/魔棒 | SAM2 点选/框选（P1） |
| 抓手 | H / 空格 | 手 | 平移画布 |

底部：蒙版颜色 swatch、透明度滑杆（默认 38%）、帮助 `?`。

## Canvas

- 背景：深色点阵 `#0A0D12`；图片带 24px 阴影和 1px 边框。
- 图片：居中，支持 10%–400% 缩放；空格拖拽；`+/-` 缩放；双击适应窗口。
- 蒙版：
  - 编辑：青色 `#3DD6C4`，38% 填充 + 1.5px 虚线描边。
  - 保护：珊瑚红 `#FF6B6B`，26% 填充 + 虚线描边 + 锁图标。
  - 选中的 region：描边加粗到 2.5px，显示控制点。
- Region chip：`R1` / `R2` / `K1`，位于蒙版左上角；点击选中卡片；颜色与操作对应。
- 对比：
  - 分割模式：中央竖直手柄，左原图/右结果；拖动改变分割位置。
  - 切换模式：按住 `\` 临时看原图；松开回到结果。
- 左下 HUD：`62% · 3376×6000 · 选区 12.4%`；右侧小字 `示意构图`（仅设计稿）。
- 右下：缩略图/适应窗口/100% 三个小按钮。

## Inspector

### Tabs

`编辑区域 (2)` · `保护 (3)` · `历史 (4)`

### Job status card

- 状态点：绿色空闲 / 琥珀排队 / 青色生成中 / 红色失败。
- 顶部 Agent 胶囊与状态栏显示 `5 个区域（2 edit / 3 keep）`。
- 文案：`本地 GPU · Qwen-Image 2.1`；`空闲` 或 `排队中 · 前面 1 个 H3 任务`。
- 估计：`约 25–40 秒`；生成中显示进度条和已用时间；失败显示错误摘要 + 重试。

### Region card（编辑）

```text
┌ R1 ─ 下颌 / 颈线 ─────────────── 精修 ▾  👁  🗑 ┐
│ [mask 缩略图]  套索 · 羽化 18px · 覆盖 4.2%    │
│ Prompt                                          │
│ 收窄下颌线，减轻双下巴，保留脸型、眼镜与表情。   │
│ [自然收下颌] [保留眼镜] [不要磨皮]              │
│ 强度 ───────●──── 80%    保护 ○                │
│ [预览此区域]                              [删除]│
└─────────────────────────────────────────────────┘
```

- 非选中区域折叠成一行摘要（名称 + 蒙版信息 + 一行 prompt），只展开当前区域；右侧始终能看到全部区域和生成按钮。
- 标题可编辑（inline）。
- operation 下拉：精修 / 替换 / 移除 / 换装 / 保护。
- mask 缩略图点击后画布高亮该区域。
- Prompt 支持多行、`Cmd+Enter` 生成。
- 建议 chips 来自模板库（本地）。
- 强度：0–100%，默认 80%；低于 40% 提示“可能看不出变化”。
- 保护开关：开启后该区域从生成 mask 中扣除，并显示珊瑚红。
- `预览此区域` 只生成该区域；如果多个区域选中，按钮为 `预览选中区域`。

### Keep card（保护）

- 珊瑚红 chip `K1`，标题 `宝宝脸部 / 背景`。
- operation 固定为“保护”，prompt 置灰。
- 说明：`此区域不会被模型修改；生成时自动从编辑蒙版中扣除。`
- 可设置“保护强度”：完全锁定 / 允许颜色微调（默认完全锁定）。

### 生成参数卡

- 位置：保护区域下方。
- 内容：模型（Qwen 2.1）、输出分辨率（1280px）、种子（自动）、生成路线（Inpaint Crop/Stitch）、羽化（18px）。
- `高级` 打开更细的参数（步数、CFG、区域独立 seed）。

### Sticky actions

- 主按钮：`生成预览`（Enter）；生成中变为 `取消任务`。
- 次按钮：`应用到图像`（生成成功后可用；写入新版本）。
- 小字：`仅处理选中区域 · 输出分辨率 1280px`。

### 历史 tab

- 时间线：版本号、时间、模型、seed、耗时、接受状态。
- 每条可 `查看` / `对比` / `恢复` / `删除`。
- 原图 V1 永远不可删除。

## Filmstrip

- 横向版本缩略图，高度 88px。
- 当前版本青色边框；已接受版本右上角绿色 `✓`。
- `+` 新版本占位（灰色）。
- 右侧按钮：`接受此版本`（主） / `对比原图`（次）。

## 导出弹层

- 格式：PNG（默认）/ JPG（质量 95）。
- 尺寸：原尺寸 / 长边 4096 / 长边 2048。
- 附带：`regions.json`、`masks/`、`versions.json` 复选。
- 路径：默认 `~/Pictures/MaskCanvas/<project>/`；可修改。
- 按钮：`导出` / `取消`。
- 隐私提示：`全部在本地完成，不会上传。`

### Typography

- 字体：`Inter, "PingFang SC", "Noto Sans SC", system-ui, sans-serif`。
- 字号：11（caption）、12（label）、13（body）、15（card title）、20（section）、28（empty title）。
- 行高：1.45；数字用 tabular-nums。
- 字重：400 / 500 / 600。

### Spacing / radius / shadow

- Spacing: 4 / 8 / 12 / 16 / 20 / 24 / 32。
- Radius: 6（chip）/ 10（button）/ 14（card）/ 999（pill）。
- Shadow: `0 12px 40px rgba(0,0,0,.35)`（图片/弹层）。
- Focus ring: `0 0 0 2px #0E1116, 0 0 0 4px #3DD6C4`。

### Icons

- 线性图标，1.8px stroke；20px（工具栏）/ 16px（卡片内）。
- 工具 tooltip 必须带快捷键。

## States

| 状态 | UI |
|---|---|
| 空项目 | 中央 dropzone：`拖入一张图片，或从剪贴板粘贴`；最近项目列表 |
| 无区域 | 画布上浮动 coach mark：`框选要修改的区域`；右侧 Inspector 显示引导卡 |
| 无 Agent | 顶部灰色 `Agent 未连接`；区域仍可编辑/生成；点开显示启动命令 |
| GPU 忙 | Job card 琥珀：`H3 正在使用 GPU · 预计...`；生成按钮保持可用但提示会排队 |
| 生成中 | 画布顶部细进度条；Job card 显示已用时间；可取消 |
| 生成失败 | Job card 红色，错误摘要 + `重试`；mask/prompt 不丢失 |
| 生成成功 | 新版本进入 filmstrip，自动选中；主按钮变为 `应用到图像` |
| 已接受 | 版本缩略图绿色 `✓`；导出默认使用已接受版本 |
| 图片过大 | 预览降采样；HUD 显示原尺寸；导出保持原尺寸 |
| 离线 | 顶部红色 `本地服务未连接`；只读模式；提供重启命令 |

## Responsive

- ≥1280：完整三栏。
- 960–1279：Inspector 变为右侧抽屉（按钮打开），工具 rail 保留。
- <960：工具 rail 变底部工具栏；画布全宽；Inspector 全屏抽屉。
- 设计/实现优先桌面；移动端只做查看/审批，不做精细涂抹（P1 再评估）。

## Accessibility

- 所有按钮有 `aria-label`；工具支持键盘切换。
- 颜色不是唯一语义：蒙版同时用虚线/锁图标/文字。
- 对比手柄支持键盘左右箭头。
- 文本对比度 ≥ 4.5:1；焦点环清晰。
- 不用动画表达关键状态；队列/失败有文字。

## Microcopy

- 生成按钮：`生成预览`（不是“生成”，避免误以为直接改原图）。
- 应用按钮：`应用到图像`（生成成功后出现）。
- 保护卡：`此区域不会被模型修改`。
- 队列：`前面还有 1 个 H3 任务，预计 3 分钟`。
- 失败：`生成失败：显存不足。已保留你的选区和提示词。`
- 导出：`原图、当前版本、蒙版和 JSON 都会保留。`
